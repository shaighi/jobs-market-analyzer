# Pakistani Job Market Analyzer 📊

A real-time job market analysis platform that provides insights into Pakistan's tech job market.

## Features

- 📈 **Dashboard** - Real-time job statistics and trends
- 🎯 **Resume Matcher** - Match your skills with available jobs
- 💰 **Salary Predictor** - Predict salary based on role, location, and experience
- 📊 **Data Visualization** - Interactive charts and graphs
- 🌍 **Location Analytics** - Jobs distribution across Pakistani cities

## Tech Stack

- **Backend**: Python, Flask
- **Frontend**: HTML, CSS, JavaScript
- **Data Processing**: Pandas, BeautifulSoup
- **Visualization**: Plotly

## Installation

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/job-market-analyzer.git
cd job-market-analyzer

# Create virtual environment
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # Mac/Linux

# Install dependencies
pip install -r requirements.txt

# Run application
python app.py
```

Visit: `http://localhost:5000`

## Features Demo

### Dashboard
- View total jobs, salary statistics, and city distribution
- Interactive charts for top skills and companies

### Resume Matcher
- Enter your skills and find matching job positions
- See match percentage for each job

### Salary Predictor
- Predict expected salary based on:
  - Job title
  - Location (Karachi, Lahore, Islamabad, Peshawar)
  - Years of experience
